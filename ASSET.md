# Artwork and attribution

The default pixel robot is original programmatic artwork created in
`src/AvatarArt.cs`. `assets/companion.png` is its generated bitmap. Both are
covered by this repository's MIT license.

The screenshots use this original mascot and explicitly labeled sample data.
No DeepCool, OpenAI, anime, or game artwork is bundled.

Users can point `avatarPath` at their own local PNG/JPEG. An older personal
installation's custom portrait remains local when upgraded and is not included
in the repository or releases. Custom assets retain their own applicable rights;
the application's license does not change them.

DeepCool, D-Cast, DeepCreative, Codex, ChatGPT and Your dot are referenced to
describe compatibility. Rei Cast is an independent community project.
