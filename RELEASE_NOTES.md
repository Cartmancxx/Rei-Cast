Rei Cast now supports D-Cast extended-display coolers through a generic Windows
display interface. Choose other resolutions, retain a monitor identity across
display-number changes, and use landscape, portrait or compact layouts with
proportional scaling.

Includes local Codex task observation, an opt-in Dot reply publisher, clock,
configurable weather, performance counters, current-user logon startup and bounded
wake recovery. The public package ships original MIT-licensed pixel artwork.

Physical validation currently covers LT360 VISION only. Other D-Cast-enabled
models use the same selectable Windows display path but need hardware reports.
The Dot bridge requires explicit publishing from the connected Dot; it does not
subscribe to cloud conversations. Actual reboot/logon and vendor wake transport
remain separate hardware checks.
